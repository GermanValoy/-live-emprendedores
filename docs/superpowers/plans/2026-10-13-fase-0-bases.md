# Fase 0 – Bases · Plan de implementación

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Dejar publicada en Vercel una app Next.js con el estilo "Vivo y vibrante", instalable en el celular, con login de Google, tabla `users` protegida por RLS, utilidades de formato y pruebas automáticas corriendo en GitHub.

**Architecture:** App Next.js 16 (App Router, carpeta `src/`) que habla con Supabase mediante `@supabase/ssr` (sesión en cookies, renovada por `src/proxy.ts`). La estructura de la base se define con Drizzle (esquema + migraciones en `drizzle/`), y las reglas de seguridad (RLS, permisos, alta automática) van en una migración SQL escrita a mano. Las pruebas se dividen en tres capas: Vitest (unitarias), Vitest de integración contra Supabase y Playwright (punta a punta, tamaño celular).

**Tech Stack:** Next.js 16 + TypeScript estricto, Tailwind CSS 4 + shadcn/ui, Supabase (Auth + Postgres), Drizzle ORM / drizzle-kit, Vitest + Testing Library, Playwright, GitHub Actions, Vercel. Gestor de paquetes: npm (Node 22).

**Spec:** [docs/superpowers/specs/2026-10-13-fase-0-bases-design.md](../specs/2026-10-13-fase-0-bases-design.md)

- Toda la interfaz y los mensajes al usuario en español rioplatense (voseo). Nunca mostrar errores técnicos ni en inglés.
- TypeScript estricto (`strict: true` + `noUncheckedIndexedAccess: true`).
- Antes de usar la API de cualquier librería, verificar la firma en la documentación actual (Context7 si está autorizado; si no, la documentación oficial). Si el código de este plan no coincide con la versión instalada, manda la documentación: ajustar y anotarlo en el commit.

## Review Focus

1. **Redirección abierta en el login**: si alguien arma un enlace `/auth/callback?next=https://sitio-malo.com`, la persona debe terminar en Tu Feria Live, nunca en otro sitio → pruebas de `rutaSegura` (Tarea 7).
2. **Cuenta de Google sin nombre o sin foto**: igual debe tener un nombre para mostrar y la pantalla no debe romperse → prueba de integración "sin full_name" (Tarea 6) y prueba e2e con usuario sin foto (Tarea 7).
3. **Montos inválidos** (con decimales, `NaN`, negativos): no se debe mostrar un precio inventado → `formatARS` lanza error en no enteros y formatea negativos (Tarea 2).
4. **Fechas cerca de la medianoche**: una hora UTC de madrugada pertenece al día anterior en Tucumán → pruebas de `formatFechaTucuman` (Tarea 2).
5. **Cookie de sesión vencida o corrupta**: entrar a `/cuenta` con una cookie inválida debe llevar al inicio, sin pantalla de error → prueba e2e (Tarea 7).

- [ ] **Step 4: Implementar `formatARS`**

`src/lib/format/plata.ts` (se agrupa a mano porque `Intl` en español no separa los miles de 4 cifras):

```ts
/** Convierte centavos enteros (ARS) al formato argentino: 800000 → "$8.000". */
export function formatARS(centavos: number): string {
  if (!Number.isSafeInteger(centavos)) {
    throw new TypeError("El monto debe ser un número entero de centavos");
  }
  const absoluto = Math.abs(centavos);
  const pesos = Math.floor(absoluto / 100);
  const resto = absoluto % 100;
  const miles = String(pesos).replace(/\B(?=(\d{3})+(?!\d))/g, ".");
  const texto = resto === 0 ? `$${miles}` : `$${miles},${String(resto).padStart(2, "0")}`;
  return centavos < 0 ? `-${texto}` : texto;
}
```

- [ ] **Step 8: Implementar `formatFechaTucuman`**

`src/lib/format/fecha.ts` (se arma con `formatToParts` para no depender de comas o espacios que cambian entre versiones):

```ts
const formateador = new Intl.DateTimeFormat("es-AR", {
  timeZone: "America/Argentina/Tucuman",
  day: "2-digit",
  month: "2-digit",
  year: "numeric",
  hour: "2-digit",
  minute: "2-digit",
  hourCycle: "h23",
});

/** Muestra una fecha guardada en UTC en hora de Tucumán: "13/10/2026 15:30". */
export function formatFechaTucuman(fecha: Date | string): string {
  const valor = typeof fecha === "string" ? new Date(fecha) : fecha;
  if (Number.isNaN(valor.getTime())) {
    throw new RangeError("Fecha inválida");
  }
  const partes = Object.fromEntries(
    formateador.formatToParts(valor).map((p) => [p.type, p.value]),
  );
  return `${partes.day}/${partes.month}/${partes.year} ${partes.hour}:${partes.minute}`;
}
```

```ts
const DESTINO_POR_DEFECTO = "/cuenta";

/** Devuelve el destino solo si es una ruta interna; evita redirigir a otros sitios. */
export function rutaSegura(next: string | null): string {
  if (!next || !next.startsWith("/") || next.startsWith("//") || next.includes("\\")) {
    return DESTINO_POR_DEFECTO;
  }
```

```ts
import { createServerClient } from "@supabase/ssr";
import { NextResponse, type NextRequest } from "next/server";
import { supabaseEnv } from "./env";

const RUTAS_PROTEGIDAS = ["/cuenta"];

function esProtegida(ruta: string) {
  return RUTAS_PROTEGIDAS.some((r) => ruta === r || ruta.startsWith(`${r}/`));
}

/** Renueva la sesión en cada pedido y saca al inicio a quien entra sin sesión a una ruta protegida. */
export async function updateSession(request: NextRequest) {
  let supabaseResponse = NextResponse.next({ request });
  const { url, publishableKey } = supabaseEnv();

  const supabase = createServerClient(url, publishableKey, {
    cookies: {
      getAll() {
        return request.cookies.getAll();
      },
      setAll(cookiesToSet) {
        cookiesToSet.forEach(({ name, value }) => request.cookies.set(name, value));
        supabaseResponse = NextResponse.next({ request });
        cookiesToSet.forEach(({ name, value, options }) =>
          supabaseResponse.cookies.set(name, value, options),
        );
      },
    },
  });

  let conSesion = false;
  try {
    const { data } = await supabase.auth.getClaims();
    conSesion = !!data?.claims;
  } catch {
    conSesion = false; // cookie vencida o corrupta: se trata como sin sesión
  }

  if (!conSesion && esProtegida(request.nextUrl.pathname)) {
    const destino = request.nextUrl.clone();
    destino.pathname = "/";
    destino.search = "";
    return NextResponse.redirect(destino);
  }

  return supabaseResponse;
}
```

```ts
import { createServerClient } from "@supabase/ssr";
import type { Session } from "@supabase/supabase-js";

type Cookie = { name: string; value: string; domain: string; path: string; sameSite: "Lax" };

/** Convierte una sesión en las cookies que espera la app, usando el mismo formato de @supabase/ssr. */
export async function cookiesDeSesion(sesion: Session): Promise<Cookie[]> {
  const guardadas = new Map<string, string>();
  const supabase = createServerClient(
    process.env.NEXT_PUBLIC_SUPABASE_URL!,
    process.env.NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY!,
    {
      cookies: {
        getAll: () => [...guardadas].map(([name, value]) => ({ name, value })),
        setAll: (lista) =>
          lista.forEach(({ name, value }) => (value ? guardadas.set(name, value) : guardadas.delete(name))),
      },
    },
  );
  const { error } = await supabase.auth.setSession({
    access_token: sesion.access_token,
    refresh_token: sesion.refresh_token,
  });
  if (error) throw error;
  return [...guardadas].map(([name, value]) => ({
    name,
    value,
    domain: "localhost",
    path: "/",
    sameSite: "Lax",
  }));
}
```
